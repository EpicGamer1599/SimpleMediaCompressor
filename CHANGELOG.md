# Changelog

## 1.0.0

Initial release.

- Added the Pygame desktop interface with dashboard, compression controls, queue, history, settings and about pages.
- Added isolated Pillow and FFmpeg workers with concurrency limits and process-level pause/resume/cancellation.
- Added bulk folder discovery and mixed media jobs.
- Added protected source files, safe collision handling, temporary output publication and cleanup.
- Added EXIF orientation, transparency protection, supported animation preservation and optional metadata retention.
- Added FFmpeg discovery, capability validation and optional H.264 hardware encoders.
- Added local settings/history, before/after results, previews, notifications and logging.
- Added automated media integration/UI tests and a windowed executable build script.
